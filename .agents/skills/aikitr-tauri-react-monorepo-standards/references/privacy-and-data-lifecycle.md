# 14 隐私与数据全生命周期

适用：用户内容、身份标识、设备信息、诊断、导出或远端副本。数据 domain 负责人维护用途与生命周期，平台/服务/诊断接收端各自执行，产品与组织数据治理负责人确认承诺及适用政策。此处定义工程控制；地区/行业的法定义务由实际适用规则与负责方确认，不据通用模板宣称法律合规。

## PRIVACY-INVENTORY · 数据清单与最小化

**必须**对实际数据记录：类别/敏感性、用途与最小字段、来源、主体/租户范围、存储与副本、访问者/接收方、保留与删除触发器、加密/导出策略、所有者。清单包含数据库、缓存/索引、outbox、附件、日志/dump、备份、第三方服务和同步设备；公开目录名或匿名 ID 不自动意味着匿名数据。

- **默认**本地优先且最少采集，远端处理按实际产品需求；分析、支持和审计各自定义用途，不能借一个诊断入口无限采集内容。
- **必须**把产品开关、用户选择和组织策略对采集/上传/缓存的效果写清楚；适用告知/同意由实际治理流程确定。关闭时停止相应行为并明确既有副本处理，不假设客户端禁用会自动删除远端数据。
- **默认**用户内容不进入通用 fixtures、错误参数或遥测标签。必要支持样本按最小化、访问与期限管理；安全日志契约沿用可观测性章节。

## PRIVACY-ACCESS · 访问、导出与共享

- **必须**按主体/租户与数据用途校验读取、导出、共享和支持访问；批量/异步导出在执行与领取时确认身份，链接/临时文件限定作用域与有效期。脱敏数据仍按实际可关联风险处理。
- **默认**导出提供可理解的范围、版本/格式与安全错误，不默认打包凭据、整库或所有诊断。普通用户自己的本地导出不强制引入审批平台；跨主体或组织受限数据按真实授权流程。
- **必须**为接收方、委托处理或跨系统副本明确删除/保留责任与结果确认；第三方 SDK 默认行为需核验，不能凭自己未调用上传函数就宣称未采集。

## PRIVACY-RETENTION · 保留、删除与物理范围

- **必须**将保留依据、期限或可追踪触发事件和执行者记录为可执行策略；必要审计/受限保留单独隔离并说明访问限制、到期清理与未删除范围，不把所有副本无期限保留。
- **必须**区分退出会话、移除本地缓存、删除工作区、删除账户与撤销共享；界面承诺、确认范围、执行效果和不可逆影响一致。明确可重建与唯一数据、用户选择及失败后的恢复，不能把注销伪装成所有数据已删除。
- **必须**区分逻辑不可访问、物理清除、备份到期与密钥销毁。普通文件删除/数据库 DELETE 不证明 SSD、WAL、快照或第三方副本已安全抹除；密码学删除只在独立密钥范围、所有密钥副本与恢复材料满足条件时作对应声明，不销毁其他用户共用密钥。
- **默认**不可变备份按有限保留期过期并限制访问；明确何时清除以及恢复时如何应用当前删除状态。主动可编辑副本按策略及时处理，不能因备份限制放弃主数据与待执行队列治理。

## PRIVACY-DELETION · 删除协调与防恢复复活

**提供账户/工作区删除，或删除涉及多个副本、异步/在途任务时必须**有可恢复、幂等的请求/处理记录：请求 ID、已验证主体/范围、处理代次/状态、各副本步骤与结果、受限保留/失败、完成定义及必要的最小证明。记录自身也有保留期，不为证明删除而永久存储原内容。纯本地的协调删除可用持久化操作日志，无需强建远端删除服务。

**单一对象同步删除且无副本/任务协调时**使用对应存储的可靠操作与明确成功/失败反馈，验证所有权、范围与不可逆影响即可；不要求为每次删除单个文件新建独立任务登记系统。若随后引入同步、索引、备份承诺或后台操作，重新判断副本与恢复边界。

**默认流程**：确认范围与授权 → 禁止该范围新写入/共享/导出 → 停止或隔离在途任务与 outbox → 删除/隔离活动副本 → 通知并确认接收方 → 按策略处理备份及受限保留 → 记录实际结果。已发送操作结果不明时继续核对，不能只删除客户端队列就保证远端没有执行。

- **必须**让删除和并发上传、迟到结果、再次登录、恢复旧备份与离线设备重连有明确冲突规则；旧数据不得绕过权威删除状态重新进入可用或同步范围。
- **默认**使用最小 tombstone/删除代次和服务端撤销状态协调；具体机制可替换，关键是恢复与开放访问/同步前先核对并重放仍适用的删除控制。删除记录保留与最长离线/备份恢复窗口一致；记录过期后以重新取权威快照等策略处理，不能无条件重放旧数据。
- **必须**如实区分请求已接受、活动数据已删除、等待接收端/备份过期、受限保留、失败与完成。离线客户端不能证明未连接副本已清除；没有证据的物理删除或全局完成不标为成功。

## PRIVACY-ACCEPT · 验收证据

提供数据/副本清单、策略与实际执行结果；测试删除期间上传、账户切换、离线重连、失败重试、备份恢复后开放访问前核对、第三方接收端确认及保留到期。检查导出/证明记录不含无必要内容，删除恢复流程不会清空其他主体数据。

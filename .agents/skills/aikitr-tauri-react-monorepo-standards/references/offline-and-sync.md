# 08 离线操作与同步协议

适用：产品承诺离线读取、持久化远端修改或多设备同步时。纯本地 Rust 文件操作不需要网络同步队列。Query 缓存持久化仅保存读缓存，不会自动提供可靠离线写入。domain 定义冲突与命令语义，平台/后端实现可靠存储与执行，应用展示同步状态。

## SYNC-STATE · 能力与状态定义

**必须**先明确离线模式：只读旧数据、允许草稿、允许排队修改，还是完整多设备同步；标明数据新鲜度、支持的操作与限制。`navigator.onLine` 只作连接提示，实际服务可达性和请求结果决定同步状态；LAN 可用不能证明后端可达。

| 操作状态               | 用户可见语义                                 |
| ---------------------- | -------------------------------------------- |
| 本地已持久化/待发送    | 数据仅在本机安全保存，尚未得到服务端提交确认 |
| 发送中                 | 可能已到达后端；取消等待不能保证服务端未执行 |
| 已确认                 | 后端返回可核对的业务结果/版本                |
| 待核对                 | 请求结果不明，例如超时或响应丢失             |
| 冲突/权限阻断/永久失败 | 需要用户或规则明确处理，不能无限自动重试     |

这些状态属于操作模型，读缓存可独立拥有 stale/loading 状态；不得把乐观 UI 更新提示为远端已保存。

## SYNC-IDEMPOTENCY · Outbox 与幂等契约

- **必须**令可恢复操作拥有持久稳定的 operation ID、协议版本、主体/租户/工作区、资源、操作类型、payload、期望资源版本、前序依赖、状态与重试信息；payload 从白名单构造，不把 token 持久化到队列。
- **默认**本地业务修改与 outbox 记录在同一事务提交，先持久化再发送；重启/升级后能恢复。不适合共同事务的文件副作用需要日志/检查点/对账，不能凭 outbox 名称宣称原子性。
- **必须**由后端或可信执行者实现匹配的去重契约：幂等键按真实授权主体与操作作用域隔离，绑定 payload 内容；相同键不同请求返回明确冲突。重复请求返回原结果或可查询状态，去重和业务提交形成可靠一致机制。
- **必须**声明去重保留期限与队列最大可重放期限，避免客户端超出去重窗口仍盲目重放。只在客户端生成 UUID 不能防止服务端重复执行；只有去重记录但和业务副作用不一致也不能保证效果一次。
- **未有幂等/状态核对契约时**，结果不明的非幂等操作进入待核对/人工处理，停止自动重放。幂等方法名、HTTP POST 和“最多重试三次”都不能单独保证业务效果安全。

## SYNC-SCHEDULING · 调度、冲突与生命周期

- **默认**按资源/业务依赖保证必要顺序，独立任务有界并发；多个窗口/进程需要一个调度协调者或带租约/版本防护的抢占机制。旧 worker 失去资格后不能覆盖新 worker 的状态。
- **必须**重试使用退避/抖动、截止和次数/队列容量上限；区分未发出、结果不明、限流、认证失败、冲突与永久拒绝。优先核对结果不明操作的状态，而不是每次重建新 operation ID。
- **必须**在每次执行前检查当前主体、租户与会话代次。退出/账户切换使旧身份任务停止或隔离；保留与恢复须按明确产品策略，绝不把旧操作绑定新账号凭据执行。
- **默认**使用服务器 revision/ETag 等检测并发改变，冲突进入合并、重新获取、用户选择或业务补偿流程。删除有明确 tombstone/版本策略；设备墙钟不能作为重要业务冲突的唯一依据。
- **按需**允许非关键偏好采用有记录的最后写入策略，但时间/排序来源与丢失更新后果需明确。结构化业务数据、文件重命名不默认静默覆盖。
- **取消操作时**区分未发送可取消、已提交不可撤回和状态未知待核对；本地删除队列项不会撤销服务端已执行结果。需要撤销时是新的业务补偿操作。
- **增量同步时**持久化服务端 cursor、确认处理边界和删除信息；cursor 过期、协议变化或离线超过支持窗口时能安全重新获取快照。冲突解决和重放也适用存储迁移、权限与容量规则。

## SYNC-ACCEPT · 验收证据

验证本地提交后崩溃、服务端已执行但响应丢失、重复/乱序发送、相同 key 不同 payload、过期去重记录、多窗口抢占、退出/切换竞态、冲突/删除、限流、重启/升级恢复和队列满。检查数据库/副作用与去重记录的一致性，不能仅用 mock 返回 success。

验收包含协议说明、去重/重放期限、状态转移与恢复用例。服务端不支持所需语义时，明确降低离线写能力，不宣称 exactly-once。依据见 [资料来源](sources.md)，关联 [存储规范](storage-and-migrations.md) 与 [会话规范](identity-and-sessions.md)。

# 15 无障碍与交互验收

适用：实际可交互的 Web 与桌面 WebView 流程。UI 维护者保证组件语义，feature 负责人保证完整业务流程，平台负责人验证 OS/WebView 与辅助技术；产品/组织明确支持范围和符合性目标。使用 shadcn、Base UI 或 Radix 不自动使消费者流程合格。

## A11Y-TARGET · 目标、适用范围与声明

- **生产 Web 内容默认**以 WCAG 2.2 A/AA 的适用成功标准作为验收目标；已有合同/组织目标按实际要求记录。桌面 WebView 的内容采用对应标准，原生菜单、窗口与 OS 集成另验证平台语义；不把桌面程序笼统声明为已获 WCAG 认证。
- **必须**记录目标版本/等级、页面和完整流程、语言/主题、平台/辅助技术组合、所有者、已验证标准、未验证范围与精确例外。声称 AA 时需覆盖范围内的 A 和 AA 要求，不能仅通过几个自动规则或单个组件作整体声明。
- **默认**按风险覆盖关键任务和变化页面，例如登录、导航、表单错误、确认/取消、长列表、设置与恢复；符合性声明遵循完整页面/流程范围，不排除不方便验证的局部后仍声称整个流程通过。

## A11Y-SEMANTICS · 语义、输入、焦点与状态

- **必须**保留实际名称、role、value/state 与结构关系；优先正确原生元素，装饰图标不重复朗读，纯图标操作有可理解名称。自定义控件组合必须有相应键盘模型，ARIA 不能修复错误交互语义。
- **必须**使键盘用户完成已承诺流程：可见且不被遮挡的焦点、合理顺序、无非预期焦点陷阱、Dialog 打开/关闭与返回焦点、禁用状态和真实链接/按钮语义；鼠标 hover 不作为唯一信息或操作入口。
- **必须**把字段 label、说明、错误与控件关联，错误可定位且有修正方式；异步 loading/success/conflict 状态通过合适语义反馈，避免每个进度更新强制焦点或重复朗读。
- **默认**统一空/加载/失败/无权限/冲突/恢复状态的交互契约，保留用户输入并说明操作是否提交；高影响不可逆操作按产品规则提供确认、撤销或纠错。通知不只靠短暂 toast。
- **必须**不吞掉输入法组合和辅助输入，快捷键与平台习惯/可访问输入协调；存在超时、拖拽、复杂手势或动态认证时按目标成功标准提供必要调整/替代方式。

## A11Y-PRESENTATION · 视觉、运动与辅助技术

- **必须**依据目标标准检验文本/非文本对比、缩放与重排、触控目标等适用条件，状态不能仅靠颜色。不是所有图形/数据表都适合同一种重排，适用例外需说明。
- **默认**支持系统高对比度/forced-colors 与减少动画偏好，焦点和状态仍可辨识；关键提示与可操作性不依赖动画。长文本、RTL、字体替换和最小窗口与国际化章节共同验收。
- **必须**为承诺平台选定有代表性的真实屏幕阅读器/OS/WebView 组合，记录版本与完整任务结果；WebView 可访问树与原生菜单/对话框协作实际测试。只在 Chromium 键盘通过不证明其他 WebView 或屏幕阅读器通过。
- **按需**针对产品用户采用更多辅助输入、读屏器、放大器或外部评估；不把全部全球组合规定为每次 PR 的门禁。

## A11Y-ACCEPT · 验收矩阵与回归

| 证据                 | 可以证明                         | 仍需确认                                 |
| -------------------- | -------------------------------- | ---------------------------------------- |
| 自动语义/对比检查    | 工具能检测的规则与当前页面状态   | 任务可完成、阅读顺序、动态交互与完整范围 |
| 真实键盘与焦点流程   | 输入路径、焦点可见/返回、快捷键  | 读屏器名称/状态、跨平台辅助技术          |
| 屏幕阅读器任务       | 对应组合下的名称/结构/状态与流程 | 未测试环境与全部成功标准                 |
| 高对比/缩放/减少动画 | 对应主题与显示条件的可用性       | 其他布局/语言/任务                       |

**必须**记录实际检查对象、版本、步骤、结果与未验证项；关键交互变化在受影响消费者和平台回归。失败由组件、业务或平台所有者修复；例外不冒充符合性通过。没有新增交互的低影响改动按风险选择检查，避免每次全量重复。

标准依据见 [资料来源](sources.md)，组件契约见 [设计系统治理](design-system-governance.md)，语言/RTL 见 [国际化](internationalization.md)，平台范围见 [兼容矩阵](platform-compatibility-and-distribution.md)。

# 11 安全设计与威胁建模

适用：桌面原生能力、共享 Web、外部输入、身份或敏感数据的设计与变更。业务负责人定义资源与授权，平台负责人维护原生/浏览器边界；安全评审职责映射到实际维护者。完整安全扫描按任务与风险选择，本章节不把普通开发自动升级为全仓安全审计。

## SEC-MODEL · 资产、信任边界与触发器

- **生产默认**维护轻量威胁模型：受保护资产、数据流、可信与不可信主体、入口/权限、可能滥用、缓解措施、剩余风险、所有者与验证。简单离线工具可以是一张表，不要求专门建模平台。
- **必须**对新增/扩大原生权限、外部内容执行、身份/租户隔离、数据导出、更新链或高权限 sidecar 分析受影响的信任边界，并关联实际变更与控制证据。已有模型可更新局部；不以每次普通样式修改重做全部模型。
- **默认**用 STRIDE 或攻击路径/滥用场景选择适合的分析视角；方法名称不代表覆盖完备。capabilities、CSP、身份授权、路径隔离和进程权限各自解决不同边界，不能互相替代。
- **必须**声明攻击者能力与范围：恶意输入、受影响 WebView、普通本地用户、其他进程/账号、远端服务等。用户自己完全控制设备时，客户端密钥和本地日志不能直接提供对该用户的保密与不可抵赖保证。

## SEC-INPUT · 外部内容、文件与执行面

- **必须**在可信原生/后端执行点验证主体、资源和操作；UI 隐藏、前端类型和客户端 flag 不作为授权。批量操作逐项检查实际对象与身份范围，不能只验证一个父 ID。
- **必须**为路径访问定义受控根、允许操作、规范化/组件边界、目标或父目录的链接/重解析点策略。字符串 startsWith 和“先 canonicalize 再按字符串重开”不能独自保证没有越界与检查后替换竞态；使用目标平台支持的受限目录/句柄操作或经过验证的库，测试真实对象与操作时机。
- **启用归档导入时必须**约束条目数、累计展开字节、单项大小、嵌套深度和中断策略；压缩比可作为辅助，不能替代实际展开量上限。检查绝对路径、父目录逃逸、链接/特殊条目、重复名、大小写冲突与覆盖策略。**默认**在隔离暂存区验证后提交，失败清理只限本次所有的暂存对象。
- **必须**将用户输入作为数据传递，禁止拼接 SQL 或 shell 命令。sidecar 使用固定允许程序和结构化参数，防止参数/选项注入；文档、HTML、Markdown 等外部内容通过实际使用的安全解析/清理边界，不直接获得原生能力。
- **启用外部 URL/远端内容时必须**按用途校验 scheme、来源、重定向和允许动作；若原生/后端代取 URL，按访问范围处理内网、回环与地址变化风险。普通外部链接不因本章节自动变成网络代理功能。

## SEC-CRYPTO · 凭据、加密与进程权限

- **必须**记录密钥用途、持有者、获取、轮换、失效与恢复；加密数据和获取密钥的条件共同构成边界。把密钥放在同一个可读配置、前端 bundle 或固定 Rust 字符串，不能宣称阻止安装者提取。
- **默认**采用平台凭据存储与成熟密码库，不自创算法/随机数/协议。离线加密是否抵御丢失设备、其他 OS 用户或已登录进程，按威胁模型和实际能力说明；密钥不可恢复时明确数据损失影响。
- **默认**以普通用户权限运行应用与 sidecar；安装提权不等于运行时永久提权。必须提权的能力限定操作、参数、调用者与生命周期，不把全部 UI 变成高权限执行面。
- **必须**将自动化测试的后端执行、mock 与远程调试接口限定在测试构建/受控环境；发行产物验证其不可被普通不受信主体调用，不能只依靠“UI 没入口”。

## SEC-RESPONSE · 风险处置与安全变更

**必须**记录每项实际风险的处理：修复、移除能力、替代控制或经相应负责人接受剩余风险，并关联等级、范围和验证。已确认可利用的授权绕过、越界写入、秘密泄漏等阻断受影响能力的生产发行；整改或停用后重新验证。默认规则的替代实现按同等边界证据评审。

**生产默认**指定私密漏洞接收方式、分流负责人、支持版本和修复/披露流程；已有组织渠道优先复用。诊断附件最小化敏感数据，公开 issue 不承载真实 token 或用户文件。事件处置区分止损、凭据撤销/轮换、修复、受影响范围确认与验证，实际外部操作遵守任务授权。

## SEC-ACCEPT · 验收证据

按启用入口提供可信边界图/表、滥用场景与真实拒绝用例：越权窗口、其他账户对象、路径逃逸/链接替换、归档超限、恶意参数、测试接口在发行环境不可达。附 commit/产物、环境、控制位置、结果和未验证范围；扫描无命中不能证明全部边界安全。

依据见 [资料来源](sources.md)；具体 capability/IPC 规则见 [数据与原生边界](data-and-native.md)，身份见 [会话规范](identity-and-sessions.md)，秘密生命周期见 [配置与密钥](configuration-and-secrets.md)。

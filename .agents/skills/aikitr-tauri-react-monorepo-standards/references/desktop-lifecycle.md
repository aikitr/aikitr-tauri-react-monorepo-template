# 01 桌面生命周期与多窗口

适用：所有桌面应用；托盘、单实例、自动启动、deep link 等规则仅在启用对应能力时生效。应用原生启动层负责进程与退出；前端 app 层负责界面启动和能力注入；feature 负责自己的任务与未保存状态。窗口不是独立的数据或认证权威。

## DESKTOP-START · 启动与就绪协议

- **必须**区分进程启动、存储/迁移完成、原生服务就绪、前端订阅就绪与界面可交互。依赖未就绪时禁止接受对应写操作；关键初始化失败显示可诊断的恢复入口，不能一直停在 loading。
- **默认**把初始化写为有依赖顺序的阶段；独立读取可并行，迁移和共享资源初始化由一个原生协调者完成。非关键索引、更新查询等在可交互后按需执行。
- **必须**让首次启动、重复初始化与失败后重试具有明确结果。不要依靠 React Effect 的调用次数决定进程级初始化；开发 StrictMode 和重新挂载不应重复启动索引或迁移。
- **启用单实例时**按当前官方插件要求先注册该插件，再处理第二次启动的 args/cwd；唤醒、聚焦和打开目标由产品明确约定。单实例不替代多窗口写入协调，也不自动提供分布式锁。
- **启用 deep link/文件关联时**统一冷启动参数和运行时事件的入口；验证来源、参数和允许动作。前端尚未就绪时在原生侧有界暂存，建立领取/确认与去重协议；不能只广播一次并假设页面已监听。

## DESKTOP-EXIT · 关闭、隐藏与退出

| 动作                       | 必须明确的行为                                               |
| -------------------------- | ------------------------------------------------------------ |
| 关闭主窗口                 | 真退出或隐藏到托盘；考虑目标 OS 的产品习惯                   |
| 关闭辅助窗口               | 释放该窗口资源；不误终止其他窗口/全局任务                    |
| 托盘/菜单退出、快捷键退出  | 进入统一退出协调流程，避免各入口实现不同保存策略             |
| 系统注销、关机、强杀、崩溃 | 最佳努力清理之外，依靠已提交的持久化和恢复协议保证数据一致   |
| 更新重启                   | 排空或持久化任务后再交接；和数据迁移、会话、离线队列规则一致 |

**默认退出协议**：请求退出 → 停止接收新写操作 → 处理未保存草稿 → 等待/取消/检查点化正在运行的任务 → 原生协调者确认持久化结果 → 释放订阅、连接与子进程 → 退出。失败或超过产品定义的期限时，明确“继续等待、取消退出、强制退出”的适用条件与数据影响。流程幂等，重复请求不重复弹窗或重复提交。

**必须**在对应原生/窗口生命周期允许的阶段阻止正常关闭并协调异步工作；不能把可靠保存寄托在 React unmount、beforeunload 或进程终止后的异步回调。强杀可能没有清理机会，因此关键修改及时提交，退出 flush 只是补充。正常退出必须执行已登记任务与资源的关闭策略，释放或确认随进程终止回收的范围；等待有界，失败可见，不能让清理无限阻塞退出。实现时核对所用 Tauri API 的事件与退出语义，不套用浏览器生命周期假设。

## DESKTOP-WINDOW · 多窗口与后台任务

- **必须**列出 window label、职责、可调用能力、可见生命周期和账户/工作区范围。每个窗口各自 React tree、providers 与缓存；需要同步的是业务状态变化，不能直接共享另一个窗口的内存 store。
- **默认**Rust 持有进程级窗口管理、后台任务和可变存储协调；前端通过快照加事件更新。事件丢失或窗口重建后能重新读取快照，不把事件当作可靠持久化队列。
- **必须**定义任务在窗口关闭、应用退出、用户退出和账户切换后的策略，携带任务 ID 和所属身份/工作区。可取消、可恢复、必须完成三类任务分别处理。
- **启用 sidecar 时**记录创建者、就绪检测、超时、退出码与关闭策略；异常退出可见，重启有次数/退避上限，防止孤儿进程和重启风暴。
- **默认**恢复窗口位置与大小前检查屏幕可用区域、缩放和最小尺寸；多屏变更后窗口仍可操作。系统托盘、菜单、快捷键与窗口销毁按注册者释放。

## DESKTOP-ACCEPT · 验收证据

| 场景                                        | 通过条件                                               |
| ------------------------------------------- | ------------------------------------------------------ |
| 首次/二次启动、迁移失败、就绪前收到打开请求 | 不重复迁移、请求可领取、错误能恢复或明确停止           |
| 隐藏再唤醒、辅助窗口销毁、屏幕变化          | 权限与缓存范围正确，焦点和窗口位置可用，无资源持续增长 |
| 写入中退出、连续退出、取消退出、强杀后重启  | 正常退出确认提交；异常退出能识别并恢复一致状态         |
| 子进程失败、更新重启                        | 退出策略与任务检查点有效，无无主任务或孤儿进程         |

在承诺的目标 OS 和实际打包产物验证。平台不具备的能力注明不适用。API 依据见 [资料来源](sources.md)，资源与任务预算见 [性能规范](performance-and-resources.md)。

安装/卸载与受管发行见 [平台兼容](platform-compatibility-and-distribution.md)，测试构建的原生执行面见 [安全设计](security-and-threat-modeling.md)。

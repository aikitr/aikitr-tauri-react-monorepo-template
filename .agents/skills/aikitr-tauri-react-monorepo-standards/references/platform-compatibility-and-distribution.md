# 16 平台兼容与企业分发

适用：承诺支持的平台与发行方式；代理、企业 CA、受管设备、静默安装和组织分发按实际产品需求启用。平台负责人维护环境/集成，发布负责人维护安装与候选产物，产品定义支持周期；不把所有 Tauri 可编译平台自动声明为产品已支持。

## PLATFORM-MATRIX · 支持矩阵与淘汰

**必须**记录已承诺组合：OS 及最低/实际验证版本、CPU 架构、WebView/运行时及安装/更新模式、安装包渠道、关键系统依赖、已启用能力、验证方式/日期、已知限制、所有者与支持状态。Web 浏览器兼容独立记录；unsupported、unverified、limited 和 supported 的含义由团队定义并对用户一致。

- **默认**选择用户实际覆盖的边界版本与典型当前环境，不测全部笛卡尔积；改变最低版本、架构或关键依赖前评估用户影响、过渡与退出支持日期，记录兼容决策。
- **必须**依据当前 Tauri、Rust、插件及 OS/WebView 官方要求确认最低可用条件；本技能不永久固定最低 OS 或运行时版本。构建成功、UA 判断或某机器已有 runtime 都不足以证明目标环境可用。
- **启用 Windows WebView2 时**明确 Evergreen/固定 runtime 与在线/离线安装策略、架构和修复/更新责任，实际核对当前分发支持；固定 runtime 不免除安全更新。macOS 系统 WebView 与 Linux WebKitGTK/发行依赖按实际版本验证，不把 Chrome 结果当作等价。

## PLATFORM-INSTALL · 安装、升级、修复与卸载

- **必须**验证候选安装包的首次安装、标准用户启动、权限失败、已有版本升级和中断恢复；启用更新/修复时补充对应路径。应用 identifier、数据路径、文件关联和后台注册变更有迁移策略。
- **默认**卸载保留用户业务数据，提供产品承诺的明确清理选择；只删除本应用拥有且已确认的对象。不能把工作区文件、共享 runtime 或其他应用目录当作安装残留清空；清理范围和不可逆效果在操作前明确。
- **必须**区分更新、卸载、重装、账户删除与本地清理；installer 返回成功不能证明关联/自启动/sidecar 已正确处理。按实际能力验证快捷方式、协议关联、权限和注册项，并处理已有应用/文件所有权。
- **必须**区分 OS 代码签名/公证、更新包签名、来源完整性与组织信任策略。按渠道提供相应证据；不能只对开发二进制验证后分发另一个签名候选。无网络、无管理员权限及防护软件阻止的处理按支持范围记录，不通过关闭系统防护保证安装。

## PLATFORM-NETWORK · 代理、证书与离线环境

- **必须**分别说明 WebView fetch、Rust HTTP、插件、sidecar 和 updater 的代理/证书配置来源与信任链；某通道可用不意味着其他通道也使用系统代理或企业根证书。
- **必须**保留 TLS 链与主机名验证。企业 CA 由受控可信策略配置，范围明确并可撤销；证书失败不使用全局 accept-invalid-certs 或忽略验证作为发行默认。若采用 pinning，说明企业代理兼容、轮换和恢复条件，不未经需求强制开启。
- **承诺企业网络时必须**验证认证代理、受限域名/重定向、企业 CA、证书过期/错误主机、离线安装/更新和被阻断服务的安全反馈。凭据不进入 URL、日志或诊断导出，超时有界，旧环境缓存与身份不随代理切换跨域泄漏。
- **默认**将代理/信任配置作为平台适配能力，业务只消费请求契约；纯本地产品标记网络项不适用，不搭建无需求的代理基础设施。

## PLATFORM-MANAGED · 受管设备与组织分发（启用时）

- **必须**明确分发身份、安装作用域、渠道、组织策略来源、更新控制与故障支持责任；租户/设备策略由可信边界落实，不能由 UI flag 任意绕过。
- **默认**按实际部署工具定义静默参数、退出码、重启需求、日志位置、标准用户启动和数据保留；安装路径不包含个人硬编码目录。运行权限与安装权限分开，管理策略变更有非敏感 revision/证据。
- **必须**让受管更新与应用 updater 的责任一致，避免互相覆盖或争抢版本；离线/暂停设备重新上线后核对签名、schema 与支持窗口，不承诺任何旧版均可回退。

## PLATFORM-ACCEPT · 候选产物与支持证据

使用 [兼容矩阵模板](../assets/templates/compatibility-matrix.md) 记录目标组合与实际证据；用 [发布验收模板](../assets/templates/release-acceptance.md) 关联 commit/build、digest、工具链、签名、配置/flag revision、渠道及数据兼容。测试插件构建与实际分发安装包的差异必须显式记录，候选包另有安装启动与发行权限 smoke。

证据覆盖本次声明的安装/升级/卸载、runtime、网络及组织策略场景；无法执行的组合标记未验证并说明影响，不把模板表格存在标作支持通过。依据见 [资料来源](sources.md)，生命周期见 [桌面规范](desktop-lifecycle.md)，数据回退见 [存储规范](storage-and-migrations.md)。

# 09 国际化、时间与区域格式

适用：多语言或跨地区展示；单语言产品也需要正确区分业务日期、瞬时时间与 locale 格式。应用拥有 locale/provider 与加载策略，feature 拥有业务文案，ui 提供可注入文本和必要可访问标签，协议保持稳定非本地化标识。

## I18N-RESOURCES · 文案、资源与所有权

- **默认**按功能 namespace 组织资源，例如 `file-library.rename.title`；key 表达语义且稳定，不以整段中文/英文文本作为公共协议。目录用 BCP 47 locale 标识，遵循所选框架格式，源语言、fallback 与缺失 key 行为明确。
- **必须**区分产品文案与调试日志/错误 code。UI 将 code + 安全参数映射到本地化反馈；Rust/后端不要求返回某种用户语言才可被前端识别。
- **默认**通过具名参数与复数规则表达完整句子，不拼接片段，也不假设所有语言只需要“单数/复数”两种。翻译资源不包含运行时密钥或敏感业务值。
- **必须**保持用户输入、文件名和协议 ID 原值，不能为翻译改写或将 locale-sensitive 大小写转换用于授权/稳定主键。翻译 key、格式和占位参数在构建/检查中可校验，资源缺失有可用 fallback。
- **按需**使用 i18next 的 typed resources 或现有语言工具检查 key/参数；翻译流程记录资源负责人和变更状态，不为单语言模板预建所有语言包。

## I18N-SEMANTICS · 时间、日期、数值与排序

| 数据语义                 | 协议/存储                         | 展示与输入                                                 |
| ------------------------ | --------------------------------- | ---------------------------------------------------------- |
| 瞬时时间，如操作发生时刻 | 明确 UTC 时间或等价 epoch 单位    | 用 Intl 等按所选 locale 和时区显示                         |
| 业务日期，如账期/生日    | 独立日期值，例如明确的 YYYY-MM-DD | 不随意转成 UTC 午夜以免跨时区偏移                          |
| 未来当地日程             | 当地日期/时间 + IANA zone 及规则  | 处理 DST 不存在/重复时间；单一 offset 不代表时区规则       |
| 数量、单位、货币         | 数值/精确小数与单位或币种代码分开 | 使用区域格式；不能默认浮点金额或从展示字符串反向推断值     |
| 文本排序/搜索            | 业务规则与稳定 ID 不变            | 展示可用 locale-aware collator；文件身份仍遵循平台文件语义 |

**必须**明确 locale、时区和语言是三个概念：系统默认只作为初值，用户/组织设置优先级有记录。不能靠字符串拼日期/数字或解析本地化日期来完成业务计算。单位、百分比、货币的缩放与舍入在 domain 确定，显示层不悄悄改变金额含义。

## I18N-INTERACTION · 布局、可访问性与运行时切换

- **默认**使用逻辑方向属性，在需要 RTL 时设置 document/容器 dir；方向性图标按语义处理，品牌图标不自动镜像。不要通过视觉重排改变不合理的键盘/阅读顺序。
- **必须**产品支持的语言下保留可访问名称、label、字段错误和弹窗语义。长文本、字体 fallback、窗口缩放、键盘快捷键及输入法组合不被截断或吞掉。
- **默认**locale/方向切换通过应用注入，不依赖共享包读应用环境变量；只加载实际使用的 namespace。切换不重置未保存草稿或改变缓存/身份范围。
- **共享 ui**接受可注入的业务文案；底座确实需要 locale/DirectionProvider 时由应用正确组装。第三方组件本身的键盘、数字或日期本地化需独立核实。

## I18N-ACCEPT · 验收证据

支持语言至少覆盖源语言、目标语言和伪本地化长文本；承诺 RTL 时测试实际方向。测试零/单/多数量、缺失 key、占位参数、跨时区日界、DST、负数/小数/大值、日期/金额输入和运行时切换。各目标 WebView 核对需要的 Intl 能力，按真实缺口选择 polyfill。

规则依据见 [资料来源](sources.md)，基础组件行为见 [组件规范](naming-and-components.md)。本章处理工程语义与展示；币种或区域格式本身不代表适用的业务/法规规则。

跨语言完整交互的可访问性目标、读屏与显示条件见 [无障碍规范](accessibility-and-interaction.md)。
